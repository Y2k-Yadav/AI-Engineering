# AI Chat Bot 🤖

A simple chat bot website made with HTML, CSS and JS.

## Put it online
1. Upload this folder to GitHub.
2. On Netlify: Add new site, then Import from Git, then pick this repo.
3. Leave the build command empty. Set the publish directory to `.`
4. Go to Site settings, then Environment variables.
5. Add `myapikey` and paste your Gemini API key.
6. Deploy the site again.

## Test on your computer
1. `npm install -g netlify-cli`
2. Make a `.env` file with: `myapikey=your key here`
3. Run `netlify dev`

Never upload your `.env` file. The `.gitignore` file already blocks it.
